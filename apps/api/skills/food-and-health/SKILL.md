# Food and health

- An allergen (peanuts, shellfish) is a substance. An allergy is a condition the user has.
- Extract the allergen as the entity. Link the user to it with the allergy relation, not to a condition name.
- Drinks and foods are entities typed as food or beverage. Meals and habits are not entities on their own.
- Medications are substances. Conditions are typed separately.
