Seme — Knowledge Graph Architecture

Entity & Relationship Extraction, Storage, Traversal, and Retrieval — Issue #12

Storage Layer

  • • entities (name, type, aliases, mention_count)
  • • relationships (source→target, type, weight)
  • • entity_memory_links (many-to-many)
  • • entity_turn_links (provenance)
  • • SQLite recursive CTEs for traversal

Extraction Pipeline

  • • LLM extracts entities + relationships
  • • Entity resolution: ADD/MERGE/NOOP
  • • Canonicalize names + track aliases
  • • Link to memories and turns
  • • Runs after memory extraction

Retrieval Strategy

  • • Entity lookup by name/alias
  • • BFS traversal 1-2 hops
  • • Collect linked memories
  • • Score: direct 1.0, 1-hop 0.7, 2-hop 0.4
  • • Combined with FTS + vector search

Sleep Job Integration

  • • Decay sweep on entities/relationships
  • • Contradiction detection (conflicting rels)
  • • Dedup sweep (entity merge + alias merge)
  • • Profile recompilation with graph
  • • Archive low-confidence entities
