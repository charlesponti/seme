API-13

Pause Blocks Remember → ERR_PAUSED

Pause/resume learning: temporarily disable memory operations without losing data.

What This Tests

Tests that when learning is paused, the remember operation is blocked with ERR_PAUSED. Resume restores normal operation.

Pause Learning
→
Remember (blocked)
→
ERR_PAUSED
→
Resume
→
Remember (works)

How It Works

1

Pause

POST /pause sets a flag that blocks all memory write operations: remember, correct, forget, and extraction pipeline. Read operations (retrieve, get profile) still work.

2

Blocked Operations

Any write operation during pause throws ERR_PAUSED. This includes explicit remember, correction, deletion, and the async extraction pipeline (which checks the flag before processing).

await seme.pauseLearning(); try { await seme.rememberCommand('s1', 'Test.', turnId, 'fact'); } catch (e) { // e.message === "ERR_PAUSED: Learning is paused" } await seme.resumeLearning();
3

Resume

POST /resume clears the pause flag. All operations return to normal. Pending extractions that were blocked can be retried.

Use Cases

Privacy Mode
The user can pause learning during sensitive conversations. The system won't extract or store any memories until resumed.
Maintenance
Administrators can pause learning during system maintenance or data migration without losing in-flight data.
Testing
Developers can pause learning to test retrieval without triggering extraction.
