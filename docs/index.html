Everything your AI needs to remember

Not a filing cabinet with a search box. A complete memory pipeline — extraction, resolution, profile compilation, decay, and self-healing.

🔍

Fact Extraction

LLM-powered extraction from conversations. Hypotheticals, jokes, and pasted content are tagged — never stored as stated facts. 22/22 extraction eval.

⚖️

Conflict Resolution

ADD, MERGE, SUPERSEDE, NOOP decisions. Single-valued slots auto-supersede. Model-second path for ambiguous cases. Corroboration-based promotion.

👤

Profile Compilation

Auto-compiled user profile from active memories. Held if >20% change. 3 consecutive holds auto-publish. Version tracking.

🧹

Decay & Compaction

6 decay classes (exempt → session). Sleep job compacts stale memories. Confidence decays over time. Corroboration extends life.

🛡️

Validation Gate

Evidence must be verbatim substring of source turn. Provenance mandatory. Non-string IDs rejected. 15 validation rules.

🔄

Self-Healing

Sleep job detects contradictions, compacts duplicates, recompiles profile. Healing log tracks all actions. Reversible where possible.

🎯

Abstention Logic

Explicit abstain flag when no relevant memories. Single-word fallback only. Never hallucinates memories that don't exist.

⏸️

Pause & Resume

Pause learning (blocks remember/boundary). Retrieval and recording still work. Resume anytime. Learning state persisted.

🗑️

Deletion & Privacy

Forget by memory, slot, topic, episode. Delete all with confirmation. Export bundle with full provenance. GDPR-compliant.

📋

Review Queue

Human-in-the-loop for contradictions, adaptations, and deletions. Confirm, reject, or edit. Full audit trail.

🧠

Adaptation Store

Feedback aggregation (≥5 signals, ≥3 sessions). Proposals via review queue. User lock on dimensions. Revert support.

🧬

Identity Core

Separate immutable identity layer. Name, preferences, traits. Never auto-modified by extraction. Explicit seed only.

🚫

Boundary Rules

User directives become procedural rules. Priority-ordered. Always included in retrieval. Never auto-deprecated.

📊

Health Metrics

Counts by status, quarantine age, contradiction depth, provenance completeness, profile token estimate, learning state.

How it works

A complete pipeline from conversation to memory to retrieval. Every step is validated, resolved, and tracked.

Ingestion

1. record_turn → turns table (provenance)
2. end_session → episode created
3. Extraction pipeline (LLM) → candidates
4. Validation gate → provenance check
5. Resolver → ADD/MERGE/SUPERSEDE/NOOP
6. Profile compiler → recompile

Retrieval

1. FTS5 + vector similarity search
2. Confidence-weighted ranking
3. Decay penalty applied
4. Top-K + procedural rules
5. Abstention if no match
6. LLM-ready context bundle

Sleep Job

1. Decay confidence (time-based)
2. Compact duplicates (MERGE)
3. Detect contradictions
4. Recompile profile
5. Log healing actions

Storage

• SQLite (better-sqlite3)
• sqlite-vec (vector search)
• FTS5 (full-text search)
• WAL mode (concurrent reads)
• Local-first, no cloud required

Simple API

REST + TypeScript. Local-first. No cloud required.

TypeScript
import { MemoryService } from './api/service.js';

const svc = new MemoryService({ storageDir: './data', embeddingDim: 4 });
await svc.seedIdentityCore({ name: 'Charles' }, 'The user is Charles.');

// Record a conversation
const turn = await svc.recordTurn('s1', 'user', 'I prefer dark mode.');
await svc.endSession('s1');

// Retrieve context for a new session
const ctx = svc.retrieveContext('s2', 'What theme does the user prefer?');
console.log(ctx.memories);  // [{ value_text: 'I prefer dark mode.', ... }]
console.log(ctx.abstain);   // false

// Get compiled profile
const profile = svc.getProfile();
console.log(profile.profile_text);  // "## Profile\n- user stated: I prefer dark mode."
