The consolidation process: deduplicate entities, detect contradictions, and merge graph data.

How It Works

1

Create Duplicate Entities

Create "Ponti Studios" twice with slightly different descriptions. The sleep job should detect these as duplicates and merge them.

const ponti1 = svc.createEntity('Ponti Studios', 'organization', [], 'Company', 'user_stated', 0.9); const ponti2 = svc.createEntity('Ponti Studios', 'organization', ['Ponti'], 'Duplicate', 'user_stated', 0.8);
2

Create Contradictory Relationships

Create two relationships with the same relation type but different targets: "Charles lives in London" and "Charles lives in Edinburgh". The sleep job detects this as a contradiction.

svc.createRelationship(charles, london, 'lives_in', 'Lives in London', turnId, episodeId); svc.createRelationship(charles, edinburgh, 'lives_in', 'Lives in Edinburgh', turnId, episodeId);
3

Run Sleep Job

POST /sleep-job triggers the consolidation process. It runs 5 phases: (1) Memory dedup, (2) Graph entity dedup, (3) Contradiction detection, (4) Profile recompile, (5) Stale cleanup.

4

Verify

After the sleep job: entity count should decrease (dedup), and review queue should have contradiction items. The sleep job log records all actions taken.

Sleep Job Phases

PhaseDescriptionOutput
1. Memory DedupFind and merge duplicate memories (same slot + similar value)Merged memories, audit log
2. Graph Entity DedupFind and merge duplicate entities (same name + type)Merged entities, updated relationships
3. Contradiction DetectionFind conflicting memories/relationshipsReview items created
4. Profile RecompileRebuild profile from active memoriesUpdated profile text
