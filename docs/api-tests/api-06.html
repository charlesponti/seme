How It Works

1

Memory Kinds

Memories are classified into kinds: fact, preference, decision, goal, habit, skill, constraint, relationship, identity, context. Each kind has different semantics and slot cardinality rules.

2

List with Filters

GET /memories?status=active&kind=decision returns only active decisions. Filters can be combined: status + kind + slot + search text.

const decisions = seme.listMemories('active', 'decision'); const interests = seme.listMemories('active', 'interest'); const all = seme.listMemories('active');
3

Pagination

Results are paginated with limit and offset. listMemories(status, kind, slot, search, limit, offset). Returns { memories, total }.
