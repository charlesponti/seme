Invalid Entity Type → Error

Input validation: entity types are strictly enforced to maintain graph consistency.

What This Tests

Tests that creating an entity with an invalid type throws an error, rather than silently accepting it.

Valid Entity Types

Person & Organization
person, organization — People and companies the user interacts with.
Places & Things
place, tool, concept, event — Locations, software tools, abstract concepts, and events.
User Attributes
preference, habit, goal, skill, identity — User's preferences, habits, goals, skills, and identity attributes.

How It Works

1

Type Validation

When createEntity is called, the type is validated against the allowed list. Invalid types throw an error immediately, before any database write.

try { seme.createEntity('Test', 'invalid_type', [], 'Test', 'user_stated', 0.9); } catch (e) { // Error thrown — entity not created }
2

Why Strict Types?

Strict entity types enable: (1) type-specific queries ("show me all people"), (2) type-aware graph traversal, (3) consistent visualization, and (4) type-specific slot cardinality rules.
