2

Total Count

The response always includes total — the total number of matching memories (not just the page). This enables the UI to calculate total pages.

3

Filter + Paginate

Pagination works with all filters. listMemories('active', 'fact', undefined, 'coffee', 10, 0) returns active facts matching "coffee", paginated.

API Parameters

ParameterTypeDescription
statusstringFilter by status: active, superseded, deleted
kindstringFilter by kind: fact, preference, decision, etc.
slotstringFilter by slot: home_city, name, etc.
searchstringFull-text search in value_text
limitnumberPage size (default: 50)
offsetnumberStarting position (default: 0)
