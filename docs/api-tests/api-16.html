List Entities with Search Filter

Entity listing with type and text filters: find entities by type, name, or alias.

What This Tests

How It Works

1

Filter by Type

listEntities(type) returns only entities of the specified type. Types: person, organization, place, tool, concept, event, preference, habit, goal, skill, identity.

seme.createEntity('TypeScript', 'tool', [], 'Language', 'user_stated', 0.9); seme.createEntity('React', 'tool', [], 'Framework', 'user_stated', 0.9); seme.createEntity('Ponti Studios', 'organization', [], 'Company', 'user_stated', 0.9); const tools = seme.listEntities('tool'); // Returns: 2 entities (TypeScript, React)
2

Filter by Search Text

listEntities(undefined, search) searches entity names and aliases. Returns entities whose name or alias contains the search text.

const search = seme.listEntities(undefined, 'Type'); // Returns: 1 entity (TypeScript)
3

Combine Filters

Both filters can be combined: listEntities('tool', 'Script') returns tools whose name contains "Script".
